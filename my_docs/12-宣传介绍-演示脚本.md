# 念头到落地 —— 一次完整演示

> **说明**：工具**尚未实现**。下面是设计走查，不是已有功能的录屏。
> **全程只用 v1 能做到的事**，没有一步是"以后会有"（v2 的样子放在最后一节，单独标出）。

---

## 题目

一个小团队想定期做技术分享。**上次搞了两回就没了。**

**成果**：半小时之后，得到一份能直接发群里的方案。

下面每一步都标出：**你做了什么**（一行）→ **屏幕上立刻发生什么**。
`$0` 表示这一步不花钱不等待。

---

### 0　打开

```
┌──────────┬────────────────────────────────────┐
│（空）     │  说一句就行，不用说清楚。            │
│          │  ┌──────────────────────────────┐  │
│          │  │                              │  │
└──────────┴────────────────────────────────────┘
```

不是表单，不是空白输入框加一个"提交"，只有一句降低门槛的话。

---

### 1　你打一句话

> **你打**：`我们团队想定期做技术分享，上次搞了两回就没了`

屏幕：

```
形式    ── 用什么方式讲、一次多久
选题    ── 讲什么、谁来定
时间    ── 多久一次、什么时间
维持    ── 怎么让它不停下来

我猜了这些，不对就改：
  · 「定期」我按每两周算                      [确认] [改] [不重要]
  · 参加的人＝全组，没有门槛                   [确认] [改] [不重要]
  · 「两回就没了」的原因 —— 我不知道，这块我空着   ← 它没编
```

**第三条是这个工具跟聊天窗口的第一个分界**：它不知道就说不知道，把空位摆出来，
**不替你编一个听起来合理的原因**。而这条空位恰好是整件事的关键。

---

### 2　你填那个空位　`$0`

> **你在那条空位上直接打字**：`没人愿意讲，大家怕准备耗时间`

立刻落盘，不花钱、不等待、没有"AI 正在思考"。**你自己写的东西是你的，它不经手。**

这句话下面出现一个不起眼的按钮：

```
没人愿意讲，大家怕准备耗时间
                              [ 这条管着别的模块？→ 提成全局规矩 ]
```

---

### 3　你点【提成全局规矩】　`$0`

**联动第一次可见。** 左边四块旁边同时出现一个小标记：

```
⚖ 全局规矩
   讲者的准备成本必须低                    ← 你刚立的

形式  ⚖    选题  ⚖    时间  ⚖    维持  ⚖
```

从这一刻起，**这条规矩会自动跟着你走进每一块的讨论**，你不用再重复说一遍。

---

### 4　你在「形式」上问一句，然后走开

> **你点开「形式」，打**：`有哪几种做法？`

进度条开始转。**你不等它**，转身去「时间」，自己敲了两句：`每两周周四下午`、`一次不超过 40 分钟`。`$0`

```
形式   ⟳ 进行中（0:38）
时间   ✎ 我正在改
```

**它在跑，你在写，互不干扰。**

---

### 5　回到「形式」：三个并排的选法，其中一个被打了叉

```
① 每人 30 分钟正式分享
   准备成本：高
   ✖ 与全局规矩「讲者的准备成本必须低」冲突

② 15 分钟随便讲讲，不要求 PPT
   准备成本：低

③ 轮流带一段视频/文章，看完一起聊
   准备成本：几乎为零
   附带：每次留 10 分钟自由问答
```

**这个叉不是 AI 说的，是机器比出来的**——它比的是候选卡上「准备成本」这个字段，
和你第 3 步立的那条规矩。**AI 提的方案，被机器按你的规矩挡了一个。**

---

### 6　你选②，再从③里拽走一件东西

> **你点 ② 的【选它】**，然后**把 ③ 里的「每次留 10 分钟自由问答」拖成 ② 的子项**

③ 整张卡没被采纳，但它的一个零件被你拿走了。
未选中的 ①③ 不删，进档案各留一行"没选的原因"——**免得下个月有人再提一遍。**

> **你顺手连了一条线**：`选题` 依赖 `时间`（多久一次决定要备多少题）。记住这条线，第 9 步会用到。

---

### 7　「选题」让它写，你在它写的东西上改字

> **你在「选题」上打**：`按这个形式，选题机制怎么定？`

四十秒后草稿就地叠在「选题」上：

```
草稿（未落盘）
  职责：定每期讲什么、谁来定
  规则：
    · 谁想讲谁报，报不满就轮值        ← 你划掉了「轮值」，改成「就跳过一期」
    · 提前一周在群里贴题目
    · 题目不限技术，但要有一个"我踩过的坑"环节
    · 每期结束当场定下一期的人          ← 你划掉了，太赶
  依据：你说的「没人愿意讲，大家怕准备耗时间」

              [ 采纳 ]   [ 我再说一句 ]   [ 丢掉 ]
```

**两处是你改的，不是让它重做一遍。** 改草稿不花钱、不等待——
你握着刀，它只是把刀递过来。

注意最后一行：**它自己把「依据」指回了你在第 2 步说的那句原话**。
你随时能翻回去看它有没有理解错。

> **你点【采纳】。**

---

### 8　你说「形式」这块定了

> **你把「形式」标成【要做】**

**这一刻是全程唯一一次它跟你较真**，一次问完：

```
定为「要做」之前，还差三件：
  · 你随手写的字段「热度」没登记过 —— 是什么意思？[说明] [换成已有的] [不要了]
  · 「15 分钟随便讲讲」这条是从哪来的？          [指回原话] ← 你点了第 2 步那句
  · 子项「自由问答」还没说它管什么               [补一句]
```

补完，「形式」变成 `✓ 定了`。

**念头阶段一路零摩擦，摩擦集中在"我决定要做这个了"这一刻**——
因为在这一刻，你是愿意的。

---

### 9　你回头改了「时间」，联动第二次可见

> **你把「时间」从"每两周"改成"每月一次"**　`$0`

屏幕立刻说话：

```
✎ 时间 已改（每两周 → 每月）
⚠ 「选题」刚才那份内容依据的是"每两周"，可能不再合适
   原因：你连过一条线 —— 选题 依赖 时间
                                     [ 让它重做 ]  [ 我自己改 ]  [ 不用管 ]
```

**它没有偷偷用旧前提继续往下走，也没有替你决定怎么办。**
你连的那条线，在这里替你记住了一件你已经忘了的事。

> **你点【让它重做】**，它带着新的频率重来一遍。

---

```

│ ⚖ 讲者的准备成本必须低   │  选题                         │
│                        │  职责：定每期讲什么、谁来定     │

│   形式   ✓ 定了         │    · 谁想讲谁报，报不满跳过一期 │
│   选题   ⚑ 有草稿       │    · 提前一周在群里贴题目      │

```

**花的钱一直在你眼前，不藏在设置里。**

---

### 11　成果出来

> **你点【导出】**

得到一份可以直接发群里的 md：

```markdown
# 团队技术分享会方案

## 前提（全局规矩）
- 讲者的准备成本必须低

## 形式  ✓ 已定
15 分钟随便讲讲，不要求 PPT。每次留 10 分钟自由问答。
> 没选：每人 30 分钟正式分享（准备成本太高）／轮流看视频再聊（想先试试真人讲）

## 选题  ✓ 已定
谁想讲谁报，报不满就跳过一期。提前一周在群里贴题目。要有"我踩过的坑"环节。

## 时间  ✓ 已定
每月一次，周四下午，不超过 40 分钟。

## 维持  ⚠ 还没想
（这块你没动过）
```

**导出的东西是机械投影，不是它另写的一遍**：树的层级变标题，正文原样搬，
**没定的照实标成没定，没选的方案连原因一起留着。**

## 补一个场景：它替你记住了一个月前的事

上面那半小时装不下"跨时间"，补一小段。

一个月后，你想给分享会加一个"外部嘉宾"环节。你在「形式」里打：
`请外面的人来讲，给点讲师费`

它当场顶回来：

```
跟全局规矩「讲者的准备成本必须低」不冲突，
但跟你一个月前在「维持」里写的一句话对不上：
   「不申请预算，一有预算就要走流程，流程一来这事就死了」
                                          [ 改规矩 ] [ 换个做法 ] [ 我知道，就这样 ]
```

**它不是"读了整个项目"**——它每次只带上跟眼前这件事真正相关的那几块。
一个月前那句话你早忘了，它替你记着。

顺手你把公司去年的《技术分享复盘》拖进来。它切成 18 片、列出目录等着被引用，
**一个字都不往你的内容里写**——只是让那份材料变得"能被指到"。

---

## 再往后：从想法直接到落地（**这一段还没做**）

「维持」那块你写过一句愿望：`如果连续两期没人报名，就说明这事在死`。

现在它只是一句话。**下一步它会变成一条真能跑的检查**——每期结束自动看一眼报名数，
不对就在页面上举手；再往后，你说"去做"，它就在一个隔离的地方动手，
做完把结果摊给你看，你点头才算数。

**到那一步，从一个念头到一件做完的事，全程不用离开这个页面。**
而你现在写下的每一句"该怎么验证"，到时候都是现成的原料。

---

## 它不适合什么

**一次性的问答别用这个。** "帮我算个数"、"这段话改通顺"——直接问 AI 更快。

**它换来的东西，只在"你会反复回来改同一份东西"的时候才回本。**

这条不是谦虚，是判据：**如果你的活儿是一次性的，这个工具对你是负的。**
