# Agent Note: 工作台的卡片模型 —— 一张卡、四段、两态

Status: implemented

[English](2026-08-14-workbench-card-model.md) | 中文

## Problem

阶段 0 交付了树、闸门和两条写路径，而提需求的人看完说：这个界面没法看。错的是两件不同的事。

视觉那半是四个具体缺陷，其中一个解释了为什么它看起来是**坏的**而不只是**素的**：样式表引用了一批从未定义过的 `--dsw-*`。一个没有 fallback 的未定义自定义属性会让**整条声明**在计算值期失效，于是 `border: 1px solid var(--没有这个)` 取初始值 `border-style: none`，`background: var(--没有这个)` 变成透明 —— 结构直接消失，而不是长得难看。另外三个：字号绕开了字体刻度直接写 `px`；`ui-primitives` 里已有的组件被手搓了一遍；没有为悬浮输入框留避让，于是 tab 自己的最后一行压在它下面。

交互那半是另一个问题：树 ＋ 详情面板回答了「这个项目里有什么」，但从来不回答「这个模块是什么、它对什么负责」。而人自己的模型是卡片 —— 所有东西都是卡片，包括整个项目 —— 且一张卡固定由四段组成：名字、选内容的 tag 条、内容体、其它辅助标签与按钮。内容体是复数且异质的（简介、表格、流程、论证、图表、子模块图），因为复杂逻辑要用多种形式才说得清。

## Decision

三栏：你在哪、这是什么、这里说过什么。中间一张卡，四段两态。

### 撰写体与派生视图是两类东西

一个内容体要么有自己的真相，要么没有。表格里的数字别处不存在 —— 它是**撰写体**：落盘、可编辑、会过时。子模块图的每一个事实都来自 `children()` —— 它是**派生视图**：每次现算、不落盘、按构造不会过时。

这条切分由类型系统执行，不靠测试：`BodyPayload` 里**没有任何 `DerivedViewKind` 的变体**，所以派生视图无法被表示成可存储的内容。tag 条给派生视图加 `⁄` 前缀，并且不提供删除。

`chart` 在实现过程中从撰写体降为派生视图。让模型写图表意味着数字没有可核验的来源，而错一格画出的柱子看起来完全正常。它现在从 `table` 的某一列派生，该列每格都要匹配 `/^-?\d+(?:\.\d+)?$/` —— 不接受单位后缀、货币符号、模糊词、空格。静默失效因此变成「这个视图不出现」。

### tag 自己带着它要展开的东西

初版给 tag 一个 `key` 加一个 `kind`，内容体和派生视图各在另一张表里，并给「算不出来的 kind」留了兜底。那个兜底是**不可达的死代码**，而它掩盖的是真问题：tag 条和内容体区可以对「当前打开的是什么」给出两个不一致的答案，而不一致没有正确的兜底可选。`TagEntry` 改成判别联合，自己带着撰写体或派生视图；宿主的 `derivedViews()` 也从「返回有哪些 kind」改成「返回算好的 view」—— 一次调用给出完整答案，没有调用方需要为「被告知有、却做不出来」准备退路。

### 一张卡，两个状态

模型的草稿不是第二种卡。它把**这张**卡推进**编辑态**，而人自己的一次较大修改推进的是同一个状态：虚线边、一条带「确定／丢弃」的横栏、每一段就地可改。正因为这次塌缩，「刀在人手里」和「人的编辑零成本」变成了一条动作序列，而不是两件互相拉扯的事。

编辑态落在日志里（`workbench/scratch`），所以它活过刷新、也活过换机器；但它**不挂在节点上** —— 是 `NodeGraph.tmp` 单独一张表。注入路径拿到的类型里没有这个字段，所以「把未提交的草稿泄漏进模型请求」是**写不出来**的，而不只是没测。这个事件不涨 `rev`：`rev` 的含义是「一次提交落了地」，让一次按键推动它，会让后面的失效扫描按每个按键去算一次影响集。

`at` 由宿主用自己的时钟盖章；wire 类型 `TmpDraft` 把它去掉了，所以时钟不对（或撒谎）的浏览器写不进日志里一个时间。空 draft 是合法的，它正是「人手动进入编辑态」发出的东西 —— 在它存在之前，进编辑态的唯一入口是模型草稿，于是**对已提交卡片的人工修改其实是不可达的**。

### 简介是职责的载体，而职责只有一个家

每张卡有且只有一个简介，且不可删：`duty` 是全局骨架里代替模块正文的东西，没有它这个模块对其他所有模块都不可见。三条实现后果，全部是**跑长流程**跑出来的，不是读文档读出来的：

- 卡片**一出生就带简介**。否则新卡的 tag 条上只有派生视图，人进编辑态后没有可以写职责的地方，而闸门同时在拒绝晋升说「你没写职责」。
- 卡片渲染读的是**节点**的 `duty` 和 `body`。那是闸门、依赖集、系统提示都在读的字段。简介自己那份由 `syncBrief` 在提交点写下，只为「读日志的人和读 `bodies` 的模型看到同一段话」，**从不被当作真相读回** —— 不一致因此到不了屏幕上。
- 模型提的简介**永远替换**旧的，无论它有没有说。追加会让 tag 条上出现两个「简介」，而人无法判断职责来自哪一个；模型也没理由知道该 `replaces` 哪个 id。

### 想法在包住它的区域之外一律不可见

想法区是一棵子树，其根带 `region: 'idea'`。可见性只有一条规则：**包住它的每个想法根都得包住发起点**。父看不见，兄弟看不见，而人们最容易以为例外的那个 —— 这张卡自己的子模块 —— 同样看不见。骨架索引按视角过滤，那是它唯一可能泄漏进模型请求的地方。

想法区经卡上的 tag 进入，绝不经树；而且**只在区域真的存在时**才出现那个 tag —— 一个指向还不存在的东西的 tag，读起来是「有想法，你只是没看」。

### 设计 token 现在有门禁

`scripts/verify-design-tokens.ts` 扫描 `packages/client/*/src/**/*.css` 里每一处 `var(--dsw-…)` 读取，对照主题**以及消费方自己那张样式表**里的定义 —— 同文件里声明的局部属性能正常解析，所以判据是「这个引用解析得到东西吗」，不是「它是不是主题 token」。带 fallback 的读取合法。它一上线就抓出既有的 13 处违规，分布在另外 6 个包里，记成带 `TODO(design-tokens)` 的豁免表；豁免项若不再出现，门禁**同样失败**，所以这张表不会腐烂。

## Alternatives considered

**画布／白板库（React Flow、tldraw、Excalidraw）。** 否决。它们拥有自己的场景图，而子模块图和关系图是**派生视图**：一张人能拖成另一个形状的图，就是「内容说了什么」的第二个来源。这里的图是手绘 SVG 加分层布局，按构造只读。

**给论证图的图形态与文本态各占一格 tag。** 否决。tag 的 key 就是内容体的 id，两格得再造复合 key，且「删掉这个内容体」会出现在两个 tag 上指同一个东西。选形态是**看的方式**、不是第二份内容，所以它落在浏览器视图状态（按 body id 记），两种形态共用一格加一个开关。**默认落在文本**：图里装不下条件、否定、全称、时态，模型漏掉的东西在图上看不见，在文字里一眼就看见。

**为两个新事件类型升 `SESSION_FORMAT_VERSION`。** 按它自己的契约否决 —— 那份契约明写「加一个普通事件类型不构成升版」。这条推翻了先前已经批过的决定，好处是一个核心文件都没碰。

**把 `workbench/scratch` 标成 `ignorable`。** 做不到：envelope 定义了这个标记，但 `Session.append` 没有任何设置它的入口，全仓库没有生产者写过它。required-on-read 本来也是安全的默认 —— 读不懂这个类型的读者会拒绝整条日志，而不是静默地少恢复一块状态。JSDoc 记下它**本来合格**，并写明那条让它继续合格的站得住的约束：提交带的是整个已提交节点，而不是一个指向编辑态的引用。

**用弹窗问每一个问题。** 否决。对话框会把光标从人正在打的字上抢走，而这恰恰是「结果到达」这条路唯一不许做的事。每个问题都在原地一行里问：Enter 提交，Escape 放弃。

## Testing

`apps/web/tests/workbench-salon.e2e.ts` 在真组装的浏览器里走验收场景的人这一半 —— 出货 Web bundle、真 Typert 线、真命令、真投影 —— 九幕，无 key，record 与 replay 两模式都绿。不挂模型行、不给 replay fixture：跑出一条流就在开放的 llm 缝上**大声失败**，而不是被悄悄答掉。开场那句由宿主侧 append，因为会话还是空的时候**会话骨架根本不渲染任何视图 tab**，工作台在有人说话之前不可达。

这条道一次抓出三个单元测试抓不到的缺陷：出生没有简介的卡、能与节点不一致的简介、会追加成第二个的模型简介。它还抓出 `promote-to-constraint` 从阶段 0 起就被宿主接受，却**没有任何人可以发出它的入口**。

两个包都是 per-file 100%。场景里成对的检查落在单元测试：想法采纳前不可见／采纳后可见、`⚠` 亮起与消除、图表判据拒四类非数字、简介被删到只剩它时仍不可删、待读结果计数向上冒泡。

## Consequences

- **`⚠` 只答「哪个更旧」，从不答「它们是否真的矛盾」。** 真检查是一次模型扫描，本阶段没有。过度报告是看得见的，缺检查是静默的。
- **锚点在它所在的内容体被替换后失效。** `replaces` 会换掉持有那个对象 id 的体。
- **按模块的对话**历史**仍作为一条线累积。** 拆分注入并过滤摘要拿到了需求全部可观察的行为；它本也想买的那条成本斜率，在单会话下没有交付。
- **想法区的可见性规则统一，因此会意外一次。** 一张卡看不见挂在它下面的想法。这是刻意的 —— 另一种做法会把未确认的想法向下泄漏 —— 但这是唯一一处「区域外不可见」读起来比预期更强的地方。
- **另外 6 个包的 13 处 token 违规被记录，没有修。** 每一处该换成哪个 token 是那个包自己的设计决定。
